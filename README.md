# Todo List



A basic Todo List application that allows users to manage tasks across custom and default projects. Tasks can include notes, due dates, and priority markers, and are automatically categorized into "Today" and "Upcoming" views based on due dates.

## Features

- **Project Management**: Create and delete custom projects.
- **Task Management**: Add, edit, complete, and delete tasks with notes, due dates, and priority levels.
- **Smart Organization**: Tasks automatically populate in "Today" and "Upcoming" folders.
- **Persistent Storage**: Uses `localStorage` to keep data across browser sessions.
- **Dynamic UI**: Fully interactive user interface powered by vanilla JavaScript and DOM manipulation.
